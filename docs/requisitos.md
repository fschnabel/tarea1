
# Análisis de requisitos

## R-01: Rendimiento
Original: El descuento debe calcularse rápidamente.

Problema: No define un tiempo medible.

Propuesta RF-01: El descuento se calculará
en un máximo de 200 ms.

Pendiente: Confirmar el tiempo con el negocio.

## R-02: Clientes especiales
Original: Los clientes importantes obtendrán
un descuento especial.

Problema: No define quién es importante
ni el descuento aplicable.

Propuesta RF-02: Los clientes VIP recibirán
un descuento adicional de $10.

Pendiente: Confirmar la política VIP.
