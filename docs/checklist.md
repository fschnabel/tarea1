
# Checklist de revisión estática

- [ ] 1. ¿Los requisitos son claros?
- [ ] 2. ¿Los requisitos son verificables?
- [ ] 3. ¿Existen requisitos contradictorios?
- [ ] 4. ¿Están definidas las reglas de negocio?
- [ ] 5. ¿Se validan los valores de entrada?
- [ ] 6. ¿Se controlan los descuentos inválidos?
- [ ] 7. ¿Se utiliza igualdad estricta (===)?
- [ ] 8. ¿Se utilizan let y const en lugar de var?
- [ ] 9. ¿Las condiciones utilizan llaves?
- [ ] 10. ¿El resultado evita valores negativos
       cuando no existe una excepción autorizada?
